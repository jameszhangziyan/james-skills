Install in three moves.

Pick a platform, copy the command, and any skill drops straight into your local Codex skills folder. No accounts, no keys, no waiting.

  1. 01

    Clone the repo

    Pick any skill card and copy its GitHub URL — every card links to the upstream source.

  2. 02

    Drop into ~/.codex/skills/

    Each skill ships as a self-contained folder with a SKILL.md at its root.

  3. 03

    Restart Codex

    Skills become available in the same conversation. No rebuild, no deploy step.

macOS · zsh 
# pick any skill from the list above
git clone https://github.com/jameszhangziyan/alphaear-news.git \
  ~/.codex/skills/alphaear-news

# restart Codex and the skill shows up automatically
Linux · bash 
# same command, Linux path layout
git clone https://github.com/jameszhangziyan/wudao-ashare.git \
  ~/.codex/skills/wudao-ashare
Cloud · remote Codex runtime 
# inside a cloud Codex session, paste the URL
$/skill-install https://github.com/jameszhangziyan/baoyu-infographic
